# Contributing to Hello Civic

Thanks for your interest in contributing to Hello Civic! This is an experimental demo space from the DevEx team, and we welcome contributions that help showcase Civic's authentication capabilities.

## 🎯 What we're looking for

- **New demo projects** that showcase different Civic auth patterns
- **Improvements** to existing demos (better UX, clearer code, bug fixes)
- **Documentation** improvements (README updates, inline comments)
- **Bug fixes** and performance improvements

## 📋 How to contribute

### Adding a new demo

1. **Fork and clone** the repository
2. **Create a new folder** for your demo (e.g., `hello-fastapi/`, `hello-flutter/`)
3. **Include these essentials:**
   - A `README.md` with clear setup instructions
   - A `package.json` or equivalent dependency file
   - Working code that demonstrates a specific Civic auth pattern
   - A one-line description of what the demo teaches

### Making improvements

1. **Open an issue** first to discuss your proposed changes
2. **Fork and create a branch** for your changes
3. **Make your changes** with clear, descriptive commit messages
4. **Test thoroughly** - make sure `npm run dev` works
5. **Submit a pull request** with a clear description

## 🔧 Technical guidelines

- **Keep it simple** - demos should be easy to understand and run
- **Document everything** - assume the reader is new to Civic
- **Use modern practices** - TypeScript, ESLint, clear folder structure
- **Make it runnable** - `npm install && npm run dev` should just work

## 📝 Style guidelines

- Use clear, descriptive variable names
- Add comments for complex logic
- Keep README files concise but complete
- Use consistent formatting (we use Prettier where possible)

## 🤝 Community

- Be respectful and constructive in discussions
- Help others in issues and pull requests
- Share your demos and use cases

## ❓ Questions?

Open an issue or reach out to the DevEx team. We're here to help!
