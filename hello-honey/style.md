# hello-honey Style Guide

## Typography

**Primary Typeface:** Helvetica Now Display
- Use for headings and display text
- Bold weight for emphasis
- Black weight for maximum impact

**Secondary Typeface:** Helvetica Now Text
- Use for body text and UI elements
- Regular weight for standard text
- Medium weight for emphasis

## Colors

**Primary Palette:**
- Black (#000000) - Primary text and UI elements
- White (#FFFFFF) - Background and contrast
- Yellow (#FFFF00) - Accent and highlights

**Brand Colors:**
- Green (#00FF00) - Success states
- Pink/Magenta (#FF00FF) - Secondary accent
- Blue (#0000FF) - Interactive elements
- Red (#FF0000) - Alerts and warnings

## Logo & Branding

**Logo Mark:** 
- Arrow symbol (↗) in black circle
- Use consistently across all applications
- Maintain clear space around logo

**Brand Name:**
- "hello-honey" always lowercase
- Use Helvetica Now Display Bold
- Maintain consistent spacing and kerning

## Layout Principles

**Grid System:**
- Use 12-column grid for desktop
- Maintain consistent margins and gutters
- Align elements to baseline grid

**Spacing:**
- Base unit: 8px
- Use multiples of 8 for consistent spacing
- Maintain generous white space

**Composition:**
- Clean, minimal layouts
- High contrast between elements
- Bold, impactful typography
- Strategic use of color for emphasis

## Usage Guidelines

**Do:**
- Use bold, confident typography
- Maintain high contrast
- Keep layouts clean and minimal
- Use color strategically for impact

**Don't:**
- Overcomplicate layouts
- Use low-contrast color combinations
- Mix too many typeface weights
- Clutter the design with unnecessary elements

## Digital Applications

**Responsive Design:**
- Mobile-first approach
- Maintain readability at all screen sizes
- Preserve brand impact across devices

**UI Elements:**
- Clean, minimal buttons
- High-contrast interactive states
- Consistent iconography
- Clear visual hierarchy
